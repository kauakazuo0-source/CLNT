# CLNT — FastLocation & Cliente MQTT Duplo

Hub web para o protótipo FastLocation (consultas de endereço/CEP e mapas) e Cliente MQTT Duplo (Publisher/Subscriber por WebSocket).

## Tecnologias
- Vite 6
- JavaScript (ES Modules)
- Tailwind CSS v4
- Leaflet
- MQTT.js v5

## Rodar localmente
```bash
npm install
npm run dev
```

## Arquivos enviados nesta publicação

- `package.json`
- `index.html`
